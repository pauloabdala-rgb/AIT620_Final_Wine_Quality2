# AIT620 - Wine Quality Prediction

Final Examination Project

**Author:** Paulo Henrique Abdala Araujo

## Project Description

This project uses machine learning to predict red wine quality based on physicochemical characteristics.

## Dataset

UCI Machine Learning Repository - Wine Quality

https://archive.ics.uci.edu/dataset/186/wine+quality

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest

## Tools

Python, Jupyter Notebook, pandas, seaborn, and scikit-learn.

## Evaluation

Models are compared using accuracy, precision, recall, and F1 score.
